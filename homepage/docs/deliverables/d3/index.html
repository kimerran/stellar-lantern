D3 — Scanner in the wallet

Statement of Work: Deliverable 3 · Target: Week 3 (21–27 Sep) · Status: Planned

The six-stage scanner will run in the wallet's pre-sign review: a block_confirm verdict will hold the Sign button, registry screening will run live per counterparty, and the AI sentence will be served by the Lantern API with no key in the client. This is where the SOW's §6.3 metrics (transactions scanned, wallets that ran a scan) will start to accrue.
