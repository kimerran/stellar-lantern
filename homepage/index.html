Install the Beta

Lantern isn't in the app stores yet. On Android, it's a one-tap APK. On Chrome or Edge, load the extension in Developer Mode — about a minute either way. Both live in the same download folder.

android

On Android? Just the APK

Download lantern.apk from the folder, open it, and allow installs from unknown sources. That's it — the steps below are only for the desktop extension.

1

Download & unzip

Grab the extension package from our Drive and unzip it to a folder you'll remember.

2

Open Chrome extensions

Go to chrome://extensions in your address bar.

3

Enable Developer Mode

Flip the Developer mode switch in the top-right corner.

4

Load unpacked

Click Load unpacked and select the unzipped dist folder.

5

Pin & open

Pin Lantern to your toolbar, click the lantern, and create or import a wallet.
