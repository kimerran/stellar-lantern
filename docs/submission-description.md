# Stellar Lantern

Self-custody is the promise of Stellar — and its biggest barrier to the next million users. People lose funds not because the network fails, but because signing is opaque: a wallet shows a wall of XDR, the user taps "approve," and a drained account or a hostile contract call is indistinguishable from a coffee payment. Stellar Lantern is a security-first, non-custodial wallet for browser and Android that closes that gap. Before you ever sign, it decodes the transaction, explains it in plain language, scores its risk on-device, and gates anything dangerous behind a deliberate confirm-and-hold action — so an account-draining merge or an unrecognized operation can never masquerade as harmless. Around that core it delivers the full self-custody toolkit ordinary people actually need: biometric unlock, guardian-based social recovery, passkey smart accounts, in-wallet earning and best-price swaps, fiat on/off ramps, and a sandboxed mini-app browser for dApps. The impact for Stellar is direct: safer signing lowers the single scariest moment in crypto, letting builders onboard mainstream users onto Soroban and the classic network without asking them to trust a black box or surrender their keys.

For reviewers: the wallet runs as a Chrome/Chromium extension and an Android app from one codebase, so you can evaluate the same experience on desktop and mobile. We recommend starting on testnet — create a wallet, fund it from the friendbot faucet, then walk the flows that show the thesis: send a normal payment (see the plain-language explanation and low-risk verdict), then try an account-merge or an unfamiliar contract call to watch the scanner escalate to a high-risk hold-to-sign gate. From there, explore guardian recovery, biometric unlock on Android, supplying to an earn pool, and a swap. Everything security-critical — the risk verdict, key derivation, and vault encryption — runs on-device; keys never leave the client and no secret material is ever transmitted. Accessibility was treated as a security property, not a nice-to-have: the high-risk signing gate is fully operable by keyboard and screen reader, because a control the user can't complete is a control that gets bypassed.
